# 基于 CBR 的液压支架选型匹配算法（论文算法章初稿）

## 1. 算法总体框架
本系统采用基于案例推理（Case-Based Reasoning, CBR）的选型方法：将历史工作面
的"地质条件 → 支架型号"成功应用案例组织为案例库，对新工作面检索最相似案例，
以其用架作为推荐结果。流程：案例检索 → 特征对齐 → 相似度计算 → Top-N 去重排序
→ 差异解释生成。

案例由三表关联构成：mining_areas（矿区地质条件）⋈ working_conditions（工作面
工况）⋈ support_models（支架型号参数），共 36 条案例，覆盖 13 个非盲测矿区、
4 个主用架型（ZY21000/38/82D、ZF15000/25/45、ZY12000/28/58、ZYA29000/45/100D）。

## 2. 有效采高规则
煤层厚度≠实际采高：厚煤层（>6.5m）综放/分层开采时，机采高度由设备能力决定
（通常 3.5~4.5m），与煤层厚度无关。直接以煤层厚度作为采高特征会造成物理上
不可解释的匹配。规则：
    coal ≤ 6.5m:  eff_h = coal
    coal > 6.5m:  eff_h = mining_height → (min+max)/2 → max → min → 4.0m（默认）
可通过环境变量 EFFECT_HEIGHT_RULE=off 关闭，作为对照实验 G0。

## 3. 特征工程
数值特征（5 个）：有效采高 _eff_h、煤层厚度、倾角、硬度 f、埋深。
  - 区间型数据（如"1.0~1.045"）取中值；非法值置 None，归一化后按 0.5 中性处理；
  - min-max 归一化，scaler 以案例库拟合，目标值越界时截断至 [0,1]；
  - 煤层厚度与有效采高并存：前者承载采煤工艺/阻力量级信号，后者保证物理可比性。
类别特征（3 个）：顶板条件、矿压显现、瓦斯等级。
  - 自由文本经映射表归入标准等级（如"强冲击倾向"→冲击级）；
  - 相似度：同级 1.0 / 相邻级 0.5 / 跨级 0.0 / 缺失 0.5（中性）。

## 4. 相似度模型
    num_dist = sqrt( Σ wᵢ·(cᵢ−tᵢ)² )          （归一化加权欧氏距离）
    sim = 0.7·(1 − min(num_dist, 1)) + 0.3·mean(cat_scores)
数值占 0.7、类别占 0.3；结果保留 4 位小数。Top-N 按 support_model_id 去重。

## 5. 权重确定（三组对照）
AHP 主观权重：判断矩阵经特征向量法求解，CR=0.0145<0.1 通过一致性检验。
按特征重排后：采高 0.4203、煤层厚度（阻力代理）0.2644、硬度 0.1489、
埋深 0.0990、倾角 0.0674。
熵权法客观权重：对归一化特征矩阵求信息熵 eⱼ=−kΣpᵢⱼln pᵢⱼ（k=1/ln n），
差异系数 dⱼ=1−eⱼ 归一化得：倾角 0.3332、煤层厚度 0.2209、埋深 0.2052、
有效采高 0.1432、硬度 0.0974。
组合权重：w = 0.5·w_AHP + 0.5·w_熵权。
切换方式：环境变量 MATCH_WEIGHTS = ahp / entropy（默认）/ combo。

## 6. 留一法（LOO）评估协议
引擎对每个目标矿区自动排除同 area_id 的全部案例，天然实现留一法，
杜绝"自匹配"数据泄漏。主统计遍历全部 13 个非盲测矿区；另设 5 个盲测矿区
（is_test=1，含真实选型、不参与案例库检索）作为外部验证集。

## 7. 实验结果（四组对照）
LOO 主统计（n=13）：
  G0 未修正基线   Top-1 38%   阻力偏差 27.5%
  G1 修正+AHP     Top-1 31%   阻力偏差 25.2%
  G2 修正+熵权    Top-1 54%   阻力偏差 23.2%   ← 最优
  G3 修正+组合    Top-1 46%   阻力偏差 24.7%
外部验证（盲测 n=5）：四组 Top-3 命中率 80%~100%；G2 阻力偏差最小（18.7%）。
G2 vs G1 不一致对 3:0（McNemar p=0.25，小样本不显著但方向一致）。

结论：客观熵权显著优于主观 AHP。原因在于 AHP 将 0.42 权重赋予采高，而案例库
机采高度几乎无方差（均为 4.0m 级），判别力低；熵权自动将权重分配给方差大的
倾角与煤层厚度，与数据结构一致。有效采高规则（G1 vs G0）在命中率上无显著
差异，但消除了同煤田伪相关、提供了物理可解释性，保留为系统默认。

## 8. 失败案例分析（D5）
(1) 平朔安家岭（13.14m，实际 ZY12000/28/58）：四组全部未命中。该面煤层极厚
    却配 12000kN 中阻架，与库中所有厚煤案例（均配 21000kN 以上）趋势相反，
    属"反趋势个案"，CBR 无法从现有案例外推。启示：需补充同类型中等阻力
    综放案例，或在规则层增加"厚煤层也可选中阻架"的先验约束。
(2) 晋城寺河（5.6m，实际 ZY21000/38/82D）：G1/G2 Top-1 均为 ZY12000/28/58。
    库中 5~6m 煤层案例多配 12000~15000kN，寺河实际选型偏重（高瓦斯的
    影响未被特征完全捕获），Top-3 内均可命中 ZY21000。
(3) LOO 未命中样本（曹家滩、塔山、兴隆庄、淮北涡北、淮南顾桥）集中在
    ZY21000 与 ZF15000 两个架型簇之间互误判：二者适用条件高度重叠，
    区分依赖次级特征（矿压细节、架型结构偏好），现有 8 维特征表达不足。
    此类错误占 LOO 失误的 5/6，是案例库扩容的首要方向。

## 9. 局限与改进方向
案例库规模小（36 案例/4 架型）；类别特征映射依赖人工表；未纳入支架高度
范围与工作面采高的硬约束过滤（当前仅在 /api/supports/filter 独立实现）。
改进：扩库、引入架型结构特征、相似度-规则混合推理。
