# 提示词与参数定稿（W20-D4）

## 参数表（集中于 app/config.py，.env 可覆盖）
| 参数 | 值 | 依据 |
|---|---|---|
| LLM_MODEL | glm-4-flash | 智谱免费档，结构化抽取/复述任务足够，零成本 |
| LLM_TEMPERATURE | 0 | 选型场景禁止"创作"，防幻觉第一道闸（W17 起沿用） |
| AGENT_MAX_ITERATIONS | 6 | 工具链最深约3步(查→算→检索)，6 留一倍余量防死循环 |
| MATCH_TOP_N | 3 | 回测显示 Top-1 命中率54%，Top-3 覆盖主要候选；过多稀释讲解 |
| RAG_TOP_K | 3 | 语料仅9块，取3已覆盖大部分相关内容 |

## 提示词清单
| 提示词 | 位置 | 用途 | 关键约束 |
|---|---|---|---|
| EXTRACT_PROMPT | guide/graph.py | 工况参数抽取 | 只输出 JSON，无字段不出现 |
| ASK_PROMPT | guide/graph.py | 缺参追问 | 一句话，不解释不编造 |
| EXPLAIN_PROMPT | guide/graph.py | 推荐讲解 | 数字与 JSON 一字不差，括注 source |
| SYSTEM | agent/agent.py | 工具 Agent 总控 | 铁律四条(数字来自工具/暂无此项/注明来源/只答选型) |

## 设计原则
1. 参数收口 config，论文实验可复现（改 .env 即可做对照）；
2. prompt 留在代码原位——它们是逻辑的一部分，不是配置；
3. 所有数字类输出要么来自工具返回，要么来自模板，LLM 只做语言组织。
