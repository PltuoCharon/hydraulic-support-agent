## 五条铁律
1. SQL 只允许出现在 services 层；router/agent 出现 SQL 即视为退化
2. 同一逻辑全系统只许一份实现；两路径（HTTP API / Agent 工具）结果必须一致
3. 盲测矿区（is_test=1）永不在前端列表可见、永不入匹配候选池
4. suspect 型号默认退出一切候选池；复现旧行为仅允许 load_cases(include_suspect=True) 显式开关
5. 估算参数来源标注三处一致：DB source 字段、前端徽标、论文表述

## 服务接口签名（改动即改契约）
- matching.load_area(area_id) -> dict ；不存在抛 LookupError
- matching.load_cases(exclude_area_id=None, include_suspect=False) -> list[dict]
- matching.match_supports(target: dict, cases: list[dict], top_n=5) -> {"total": int, "items": [...]}
- matching.match_by_params(coal_thickness, dip_angle=0.0, top_n=5) -> 同上（REPL 便捷入口）
- matcher.run_match(area_id=None, coal_thickness=None, dip_angle=None, top_n=5) ；ValueError=参数互斥
- queries.list_areas(keyword=None, include_test=False) / get_area(area_id, include_test=False)
- queries.list_supports(type=None, min_force=0, max_force=99999, only_verified=True)
- queries.get_support(model_id) / verified_supports()
- queries.search_rows(table, keyword="", limit=5) ；表白名单外抛 ValueError，limit 收敛 1~10

### D.1 POST /api/calc/column-design

**用途**

根据液压支架设计工作阻力、承载立柱数量、设计压力和效率反算立柱理论缸径，
并向上圆整到内核定义的标准缸径系列；可选输入初撑力，对初撑力比进行校核。

**请求 JSON**

- `p_kn`：支架设计工作阻力，kN，必填
- `n`：承载立柱根数，必填
- `p_mpa`：设计压力，MPa，必填
- `eta`：有效系数，默认 0.9
- `p_set_kn`：初撑力，kN，可选；为空时不进行初撑力比校核

**计算实现**

仅调用：

`app/services/calc/column.py::design()`

路由层不得重复书写缸径、柱力或初撑力比公式。

**成功响应**

```json
{
  "code": 0,
  "data": {
    "d_calc_mm": "...由计算内核返回...",
    "d_std_mm": "...由计算内核返回...",
    "p_actual_kn": "...由计算内核返回...",
    "inputs": {},
    "source": "...",
    "setting_ratio_pct": "...仅输入p_set_kn时存在...",
    "setting_ok": "...仅输入p_set_kn时存在...",
    "rule": "...仅输入p_set_kn时存在..."
  }
}
其中具体字段以 column.design() 的真实返回字典为唯一依据，API 不重新定义第二套计算结果。
输入越界
{"code":1,"msg":"..."}
HTTP 状态保持 200，与现有 /api/calc/q-need 契约一致。
验证基准
D3 已有基准：
- D=320 mm

D.2 POST /api/calc/column-strength
用途
对立柱缸筒进行壁厚计算、材料应力校核及压杆稳定性校核。
该接口只负责组合调用 W33-D4 已验证的纯计算函数，不重新实现公式。
请求 JSON
壁厚计算参数：
- d_mm：缸筒内径，mm，必填
- p_mpa：计算压力，MPa，必填
- sigma_s_mpa：材料屈服强度，MPa，默认 835（当前已核实 27SiMn 数据）
- material_safety_factor：材料许用应力安全系数，默认 2.0
应力校核参数：
- sigma_max_mpa：最大计算应力，MPa，可选
稳定性校核参数：
- e_mpa：弹性模量，MPa，可选
- i_mm4：截面惯性矩，mm^4，可选
- l_mm：计算长度，mm，可选
- load_kn：轴向载荷，kN，可选
- mu：长度系数，默认 1.0
计算实现
调用：
- allowable_stress()
- wall_thickness()
- check_stress()
- euler_buckling()
位置：
app/services/calc/column_strength.py
其中：
- 壁厚计算为必执行；
- sigma_max_mpa 提供时才执行材料应力校核；
- e_mpa/i_mm4/l_mm/load_kn 四项全部提供时才执行欧拉稳定校核；
- 稳定性参数只提供一部分时应返回输入错误，不得静默跳过。
成功响应基本结构
{
  "code": 0,
  "data": {
    "material": {
      "sigma_s_mpa": 835,
      "sigma_allow_mpa": "..."
    },
    "wall": {
      "thickness_mm": "...",
      "regime": "thin|mid|thick"
    },
    "stress": null,
    "buckling": null,
    "source": []
  }
}
输入应力校核参数后：
"stress": {
  "safety_factor": "...",
  "ok": true
}
输入完整稳定性参数后：
"buckling": {
  "critical_load_kn": "...",
  "safety_factor": "...",
  "ok": true
}
输入越界
{"code":1,"msg":"..."}
HTTP 状态保持 200。
科研边界
1. 当前已核实并用于程序验证的材料数据为 27SiMn 屈服强度 σs=835 MPa。
2. 未可靠核实的材料参数不得由 API 自动猜测或补齐。
3. 壁厚公式中的薄壁、中壁、厚壁公式属于设计计算模型；其适用性受材料许用应力、安全系数、设计压力和具体结构条件影响。
4. 当前模块定位为公式复现、参数设计辅助和方案比较，不直接作为产品制造依据。
5. W33-D4 中中壁/厚壁部分的构造案例属于公式验证案例，不得在界面或文档中标注为矿井实际工程案例。
