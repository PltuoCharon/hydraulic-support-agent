# 盲测回测规约 v1（先于实验定稿，2026-08-XX）

## 测试集
is_test=1 的 5 个矿区（名单见 backtest/test_areas.txt），覆盖：大采高/综放/冲击地压/高瓦斯/一般条件

## 指标（写死，不随结果调整）
1. Top-1 命中率：推荐第1名与实际用架「同型号或同系列」占比
   - 同系列判定：型号前段一致(如ZY21000/38/82D与ZY21000/36/80D算同系列)
     或 type相同 且 工作阻力偏差≤15%
2. Top-3 命中率：前3名中任一命中
3. 阻力偏差率：|推荐阻力-实际阻力|/实际阻力，取中位数
4. 辅助观察：相似度分布、失败案例清单

## 实验组
- G1 基线：AHP主观赋权(已定稿 CR=0.0145)
- G2 熵权法客观赋权
- G3 组合赋权 0.5×AHP + 0.5×熵权(归一化后)

## 流程
对每个测试矿区：调 /api/match(LOO已排除自身) → 取Top-5 → 判定命中 → 记入CSV
