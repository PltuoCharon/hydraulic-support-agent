# 技术要点梳理（课程笔记替代版）

> 基于 W19–W24 实现提炼，作为论文/答辩的技术底稿。

## 1. 系统架构
- 前端：Vue3 + Vite + Element Plus + Pinia + vue-router（hash 路由），六页：/input /areas /result /compare /modify /chat
- 后端：FastAPI + pymysql，14 个接口（areas×3 / supports×4 / match / recalc / requirement / chat / guide / health）
- 数据：MySQL（support_models / working_conditions / mining_areas / param_dependencies / chat_messages / dict_enum）

## 2. 选型匹配算法（CBR）
- 案例推理（CBR）：以 working_conditions 为案例库，留一法（LOO）验证
- 数值特征 5 维：有效采高 _eff_h、煤层厚度、倾角、硬度 f、埋深；权重三模式（entropy / ahp / combo）
- 类别特征 3 维：顶板、矿压、瓦斯（词典映射 + categorical_score）
- 相似度 = 0.7×(1-加权欧氏距离) + 0.3×类别分均值；Top-N 按 support_model_id 去重
- 有效性：案例相似度 top1 ZF15000/25/45=0.7957 与真实用架一致

## 3. 需求值公式（工况校核线）
- 需求支护强度 q = K1·H·γ / 1000（K1=8 大采高、γ=25kN/m³）
- 需求工作阻力 F = q × (顶梁长+梁端距) × 中心距 × 1000
- 采高 8.8m → q=1.76 MPa、F=21287 kN；参数存 param_dependencies，改库即改行为

## 4. 部件重算链（/api/recalc）
- 初撑力 F0 = n·P泵·π/4·D² → 工作阻力 F = F0/初撑比 → 支护强度 q = F·η/控顶面积
- 验证：360/4/31.5 → 12825→18322kN→1.363MPa，与手算一致；η、初撑比从参数表读

## 5. 对话状态机（LangGraph）
- 阶段流：collect（收集参数）→ confirm_pending（确认）→ explained（解释+推荐）
- 流式：POST stream=true → SSE（4 字符/块），前端 fetch+ReadableStream 逐段渲染
- 追问分支：explained 后"为什么推荐它"→ 复用参数重匹配，回执理由+案例出处
- 会话：session_id + MemorySaver 持久化

## 6. 前端要点
- useChart 组合式封装：echarts 按需引入 + ResizeObserver 防抖 + dispose 清理
- Pinia 跨页数据流：conditions→result→compare→required
- 推荐卡片：stage=explained 自动 postMatch，结构化卡片嵌入对话

## 7. 数据与权威性
