## 关键技术决策
- 需求值独立接口 GET /api/requirement/?coal_thickness=，参考线与报警共用，不侵入 match 响应；
- 计算参数全部从 param_dependencies 表读（k1/rock_gamma/beam_length/eta/setting_ratio...），改库即改行为——第8项"η 闭环"在 D6 落地；
- 需求支护强度 q=K1·H·γ（K1=8, γ=25kN/m3），需求工作阻力 F=q×(顶梁长+梁端距)×中心距，依据选型论文口径（采高 8.8m → 1.76MPa / 21287kN）；
- recalc 链式公式：初撑力=n·P泵·π/4·D² → 工作阻力=初撑力/初撑比 → 支护强度=F·η/控顶面积，360/4/31.5→18322kN/1.363MPa 与手算一致；
- 结果页自治拉需求值（onMounted），不依赖输入页改动，减少耦合。
