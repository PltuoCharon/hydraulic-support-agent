# 支架数据清洗规则
1. 单位统一：高度 mm→m（÷1000）；遇 kgf/cm² → MPa 乘 0.098
2. 型号自校验：型号中的阻力/高度数字必须与参数列一致（脚本自动解析对拍）
3. 一型一行：同型号多来源时取参数更全者，其余来源并入 source 列
4. 缺失留空（None），禁止编造、禁止用"约值"填补
5. 表头英文且与 support_models 库字段一致；每行必须有 source

## 实际遇到的清洗案例
1. 型号标称 vs 说明书不一致：ZY18900/36/72D 型号解码为 3.6~7.2m，
   但厂商页技术特征写 3200~8000mm。处理：以型号解码为准入库，
   差异记入备注——实物可能非标定制。（这也是答辩可讲的数据治理案例）
2. 同型号多来源去重：ZY6800/17/35 同时见于郑煤机型谱与三一说明书，
   drop_duplicates 保留先收录行，其余来源舍弃（必要时并入 source）。
