## 5. PASS / LIMITATION / FAIL / NOT_VERIFIED

PASS：矩阵内 B/C 坐标、AB/BC/CD 残差、分支叉积、离散目标、真实数学边界及
从 D3 到 D5 的记录语义具备独立证据。POSITIVE [0,90] 的目标符合
sqrt(0.65)-0.5 mm；NEGATIVE 递减 [90,0] 符合 sqrt(0.65)+0.5 mm。

LIMITATION：absolute_mm=1e-9、relative=1e-12 下，同一相似几何 s=1 与
s=1e-8 数值分类为双解；s=1e-10 理想为双解，但 q=2e-10≤1e-9，数值分类
为退化。双分支最大实际杆长残差分别为 0 与 6.617444900424222e-24 mm；
退化不生成 C，不能把未知残差写为 0。1e-100 正输入也合法但不能可靠分辨。
最小限制反例在矩阵、测试和尺度日志中保留；没有调整求解器或原数值容差。
离散采样和记录比例不能证明连续域覆盖。

FAIL：本次明确矩阵没有发现独立证据支持的既有合同违反；不是通用正确性证明。
如 D7 扩展验证发现反例，应保留输入与日志，另立修复任务，不能改变冻结实现
来让本次 Oracle 静默通过。

独立来源核验、任意病态几何/极端尺度、优化算法效果与运行时性能。
