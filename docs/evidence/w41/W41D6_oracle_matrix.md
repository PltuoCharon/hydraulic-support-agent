## 1. 独立性与解析依据

复用 D4 request_payload / parameter 仅构造带单位及来源的输入。
期望值函数只接受原始长度、D 坐标、角度和分支，不接受生产结果。
Oracle 不调用 W39/W40 求解器、容差函数或分支辅助函数。
生产 solve_closure、sweep_rear_link_angles、evaluate_design、evaluate_candidates
只用于取得被测结果。D3 适配器产生的任务也只是被测输入传递层。

A=(0,0)，AB=a，BC=r，CD=t：

1. B=(a cos θ, a sin θ)。0/90/180/270 度用精确单位方向，避免以生产浮点
   三角函数误差作为理想几何定义。
2. q=|D-B|，φ=atan2(Dy-By,Dx-Bx)，用严格几何距离关系区分无解、相切、
   双解及重合圆；不施加 W39 距离容差。
3. 双解 α=acos((r²+q²-t²)/(2rq))，采用归一化长度计算该比例，
   C±=B+r(cos(φ±α),sin(φ±α))。这是极坐标余弦定理，独立于生产代码的
   弦足点和法向偏移算法。
4. 叉积 (D-B)×(C-B) 的正负分别验证 POSITIVE/NEGATIVE，不只验证标签。
5. 独立计算 |B-A|-AB、|C-B|-BC、|C-D|-CD 三个距离残差。

坐标断言固定为 rel=2e-13、abs=2e-14×max(AB,BC,CD)；杆长绝对残差
上限固定为 3e-13×max(AB,BC,CD)。这些是预先声明的浮点验证界限，
不是 W39 的几何分类容差，也未因执行结果而放宽。
专项第一次执行 41 项通过；随后增加未解析分支的双候选坐标验证和来源断言，
最终 42 项通过。没有修复生产代码、失败后调整断言、xfail 或 skip。

## 2. 显式锚点

机构：A=(0,0)，D=(3,0)，AB=1，BC=CD=3，长度单位 mm。

| θ | B | POSITIVE C | NEGATIVE C |
| --- | --- | --- | --- |
| 0° | (1,0) | (2,√8) | (2,-√8) |
| 90° | (0,1) | (1.5+√0.65, 0.5+3√0.65) | (1.5-√0.65, 0.5-3√0.65) |

锚点既验证 Oracle 自身，也直接验证生产闭环、D4 和 D5 中的坐标。
POSITIVE [0,90] 的目标为 √0.65-0.5≈0.306225774829855 mm。
NEGATIVE 递减 [90,0] 的目标为 √0.65+0.5≈1.306225774829855 mm。
[0,45,90] 与 [90,45,0] 两种方向、两个分支的全部坐标及目标范围均使用
独立 Oracle 期望值，完整规则采样才允许 COMPUTED。

## 4. 固定容差尺度实测

同一相似几何：D=(3s,0)，AB=s，BC=CD=3s，θ=0。
理想 B=(s,0)，C=(2s,±√8 s)，q=2s。所有 s>0 理想分类均为双解。
明确指定 absolute_mm=1e-9、relative=1e-12。
此姿态 W39 距离 scale_mm 的最大输入为 BC+CD=6s，
τ=max(1e-9,1e-12×6s)。下面三个尺度均由绝对项主导。

| s | q (mm) | τ (mm) | 独立数学分类 | W39 / D4 / D5 实际分类 | 最大实际杆长残差（双分支） | 判定 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 2 | 1e-9 | TWO_SOLUTIONS | TWO_SOLUTIONS / FEASIBLE / FEASIBLE | 0 mm | PASS |
| 1e-8 | 2e-8 | 1e-9 | TWO_SOLUTIONS | TWO_SOLUTIONS / FEASIBLE / FEASIBLE | 6.617444900424222e-24 mm | PASS |
| 1e-10 | 2e-10 | 1e-9 | TWO_SOLUTIONS | DEGENERATE / INFEASIBLE / DEGENERATE | 未产生 C，残差未知 | LIMITATION |

DEGENERATE 是程序在给定容差下的数值分类，不是该理想机构的拓扑分类。
s=1e-10 时 q≤τ，且半径相同，落入既有近重合圆心分支。未出现内部异常，
因此不记录 NUMERICAL_ERROR 或 SERVICE_ERROR。D5 保留真实数值结果，
没有把这个有效输入改记为 INVALID_INPUT。

最小限制复现输入（其余字段由既有 request_payload 构造）：

```python
payload = request_payload(
    lengths=(1e-10, 3e-10, 3e-10), d=(3e-10, 0), branch="POSITIVE"
)
# configuration.tolerance = absolute_mm=1e-9, relative=1e-12
# 独立数学期望：B=(1e-10,0)，C=(2e-10,±sqrt(8)*1e-10)
# 实际程序闭环：DEGENERATE，无 selected_pose
```

该反例保留在专项尺度测试、日志及本表中，判为 LIMITATION，不把不满足
数值分辨要求的尺度强行改成双解断言。1e-100 另调整显式合成长度下界至
1e-102，仅用于验证正长度输入可合法，不构造工程边界。

## 5. 精确边界输入与运动最小案例

单姿态 θ=0 的精确输入：

| AB/BC/CD | D | 理想状态 | 相切 C |
| --- | --- | --- | --- |
| 1/1/1 | (3,0) | 外相切 | (2,0) |
| 1/3/1 | (3,0) | 内相切 | (4,0) |
| 1/0.5/0.5 | (3,0) | 外无解 | 无 |
| 1/4/1 | (3,0) | 内无解 | 无 |
| 1/3/3 | (1,0) | 重合圆退化 | 非唯一，不能选定 |
| 1/3/2 | (1,0) | 重合圆不同半径无解 | 无 |

运动案例：相切使用 AB/BC/CD=1/2/2、D=(3,0)、[0,90,180]；无解使用
1/1.5/1.5、D=(3,0)、[0,30,90]；退化使用 1/1/1、D=(0,1)、[0,45,90]。
每组第三角独立分类为对应边界，前两角独立分类为规则双解。
分别追加一个增大 45 度的角，验证中途边界仍保留同一前三个真实样本。
全部记录实际失败索引 2，记录数 3、规则数 2；最后样本失败时记录比例为 1，
中途失败时比例为 3/4；两种情况目标都不可评价，不生成数值违反量。

## 6. 判定及未验证范围

- PASS：上述明确矩阵内，独立坐标、距离残差、分支符号、离散目标、边界及
  记录语义有独立证据支持。数学 Oracle 验证对象是 B/C，不能替代顶梁 T。
- LIMITATION：固定绝对容差不能保持任意缩小几何的拓扑分类；极小正输入
  不保证可求解或可分辨。离散样本不证明连续角域、工作高度域覆盖。
- FAIL：本次矩阵没有发现有独立证据支持、违反既有明确合同的缺陷；该结论
  仅限这些输入，不能推断任意尺度、条件数或全部工程输入无缺陷。
- NOT_VERIFIED：可中断 TIMEOUT、真实工程几何及来源等级、顶梁/高度映射、
  80 mm 工程验收、算法性能、生产有限时批量保证、未覆盖尺度与病态几何。
