# W34D2 公式链关系

## A. W33 新设计计算链

围岩条件
→ p1/p2/p3
→ q_need
→ 后续工作阻力转换层（尚未正式建立）

特点：

- 有明确来源
- 有独立纯函数
- 有API
- 有对拍
- 有边界说明

状态：

主线 active

---

## B. 历史 requirement 链

coal_thickness
→ k1·H·gamma
→ requirement intensity
→ 历史支护面积
→ requirement resistance

问题：

1. 输入只使用 coal_thickness
2. 与 W33 q_need 不是同一模型
3. beam_length + roof_end_distance 的结构意义待核
4. center_distance 当前来自参数表默认值，并非具体型号数据库字段

状态：

legacy_review

---

## C. 历史 /recalc 链

bore + pump_pressure + column_count
→ setting_load
→ / setting_ratio
→ working_resistance
→ × eta / top_area
→ intensity

问题：

1. pump_pressure 被直接作为立柱初撑压力使用
2. setting_ratio 来源/定义待核
3. eta 位于“工作阻力→支护强度”环节
4. top_area 使用 beam_length + roof_end_distance

状态：

legacy_review

---

## D. support_calc 链

bore + pressure + n
→ single thrust
→ sum thrust × eta
→ working resistance
→ / (center_dist × canopy_len)
→ intensity

问题：

1. eta 位于“柱力→工作阻力”环节
2. 与 /recalc 中 eta 物理位置不同
3. canopy_len 定义待核
4. 与新 column.py 存在单柱推力重复实现

状态：

legacy_review

---

## 结论

现阶段不得把 B/C/D 简单合并。

W34D2只登记并核定，
不删除任何API或Agent工具。

后续迁移前必须先做：

- 调用方盘点
- 数值对比
- 来源核验
- 兼容测试
