# W34D2 参数分类表

## 1. 围岩 / 矿压参数

- hm：采高，m
- l1：老顶初次来压步距，m
- lp：基本顶周期来压步距，m
- bc：控顶宽度，m
- n：直接顶充填系数
- gamma：顶板岩层容重，kN/m³
- k1：载荷估算影响系数
- k：动载荷系数

上述参数主要服务于 W33 q_need 主链。

---

## 2. 支架总体结构参数

- center_dist
- canopy_len
- beam_length
- roof_end_distance

### center_dist

标准中文：

支架中心距

单位：

m

状态：

已确认。

### canopy_len

暂用中文：

支护长度参数

单位：

m

状态：

工程定义待核。

当前历史代码将其用于：

q = F / (center_dist × canopy_len)

现有大量数据通过“架型前缀 + 高度段”经验规则补全，
因此不得直接等同于：

- 顶梁长度
- 控顶宽度
- 控顶距
- 梁端距
- 实际有效支护长度

### beam_length / roof_end_distance

属于历史 requirement / recalc 公式链参数。

当前不得认为：

beam_length + roof_end_distance = canopy_len

除非后续取得明确来源并完成口径核验。

## 3. 液压参数

- pressure_mpa
- pump_pressure
- eta
- setting_ratio

### pressure_mpa

设计计算中的立柱工作压力。

单位：

MPa。

### pump_pressure

历史 /recalc 链中的泵站压力。

当前历史算法直接用于计算 setting_load，
其与实际初撑压力之间的关系需在 Formula Registry 中继续核验。

### eta

当前系统至少存在两种使用位置：

1. column / support_calc：
   柱力总和 × eta → 工作阻力

2. legacy /recalc：
   工作阻力 × eta / 支护面积 → 支护强度

因此目前禁止把两处 eta 默认认定为同一物理系数。

后续若物理定义不同，应采用不同 canonical code。

### setting_ratio

param_dependencies 中当前值：

0.7

历史说明：

初撑力 / 工作阻力比。

注意：

不得与 W33 `column.setting_ratio()` 混同。

后者是根据：

P_set / P_rated

计算得到的结果指标；

前者是历史 /recalc 链用于由初撑力反推工作阻力的输入参数。

## 4. 材料参数

- sigma_s：屈服强度，MPa
- sigma_b：抗拉强度，MPa
- sigma_allow：许用应力，MPa
- E：弹性模量，MPa
- material_safety_factor：材料安全系数

当前 27SiMn：

sigma_s = 835 MPa

已挂核实来源。

sigma_b：

当前保持 NULL，不自动补值。

---

## 5. 几何 / 部件参数

- bore / d_mm：缸径，mm
- rod_diameter：活塞杆直径，mm
- wall_thickness：缸筒壁厚，mm
- stroke：行程，mm
- I：截面惯性矩，mm⁴
- L：计算长度，mm
- mu：长度系数

---

## 6. 安全与经验参数

目前包括：

- safety_factor
- height_margin_ratio
- q_thin_min
- q_mid_min
- q_large_min

其中若来源标记为“经验规则、待文献佐证”，
不得在页面或论文中表述为标准强制值。

---

## 7. 参数治理规则

只有同时满足以下条件，两个同名参数才允许共用同一 canonical code：

1. 物理含义一致；
2. 单位一致；
3. 公式中的作用位置一致；
4. 来源一致或明确兼容；
5. 适用范围一致。

只要有一项不满足，就应：

- 分配不同 canonical code；
- 保留公式来源；
- 标注适用范围；
- 禁止静默复用。
