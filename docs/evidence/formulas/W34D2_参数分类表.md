# W34D2 参数分类表

## 1. 围岩/矿压参数

- hm
- l1
- lp
- bc
- n
- gamma
- k1
- k

## 2. 支架总体结构参数

- center_dist
- canopy_len
- beam_length
- roof_end_distance

其中：

canopy_len 当前为历史支护长度参数，工程定义待核。

beam_length 与 roof_end_distance 属于旧 requirement/recalc 链，
暂不视为与 canopy_len 等价。

## 3. 液压参数

- pressure_mpa
- pump_pressure
- eta
- setting_ratio

注意：

eta 在不同历史公式中的位置不同，
当前不能视为单一统一物理系数。

setting_ratio 与 W33 column.setting_ratio() 不应混同：
前者是旧链参数，
后者是计算“初撑力/额定工作阻力”的结果比值。

## 4. 材料参数

- sigma_s
- sigma_b
- E
- safety_factor

## 5. 几何/部件参数

- bore / d_mm
- rod diameter
- wall thickness
- stroke
- I
- L
- mu

## 6. 参数治理规则

同名参数只有在同时满足以下条件时才能共用：

1. 物理含义一致
2. 单位一致
3. 公式位置一致
4. 来源一致或兼容
5. 适用范围一致

否则必须改用不同 canonical code。
