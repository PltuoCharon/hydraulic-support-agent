## 2. 当前已确认的典型冲突

W33D6 已修复：

- Bc 被错误显示为“支架中心距”
- N 被错误显示为“动载系数”
- L1 / Lp 中文解释错位
- QNeed 前端范围小于后端有效范围
- “需求阻力估算”与实际MPa输出不一致

当前统一：

L1 = 老顶初次来压步距

Lp = 基本顶周期来压步距

Bc = 控顶宽度

N = 直接顶充填系数

q_need = 需求支护强度，单位 MPa

## 3. 本阶段重点待核字段

### canopy_len

当前数据库用于支护面积相关计算。

但现有数据中大量值来自架型经验估算，
而厂家标称支护强度与 P/(B×L) 复算存在系统性口径差异。

因此 W34D1 暂不将 canopy_len 等同于：

- 顶梁长度
- 控顶宽度
- 实际支护长度

等待进一步依据核实。

### initial_force

数据库真实字段为 initial_force。需要确认所有来源是否统一表示：

“整架额定初撑力”

而非：

- 单柱初撑力
- 额定初撑力
- 实测初撑力

在字段确认前，不做名称升级。
