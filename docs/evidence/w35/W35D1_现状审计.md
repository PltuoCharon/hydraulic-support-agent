# W35D1 参数级 Provenance 现状审计

## 审计边界

W35D1 只冻结参数级证据模型，不执行 ALTER TABLE，
不迁移存量数据，不改变现有业务读取逻辑。

## support_models

当前 provenance 相关字段主要是：

- source VARCHAR(100)
- data_status VARCHAR(20)

data_status 当前表达整条型号记录状态：
verified / suspect。

它不能表达同一型号不同字段具有不同证据状态。

当前 verified = 166，suspect = 2。

verified 字段覆盖：

- manufacturer: 89
- type: 161
- working_resistance: 166
- height_min: 166
- height_max: 166
- intensity: 157
- weight: 14
- initial_force: 29
- center_dist: 156
- canopy_len: 156
- source: 166

## source 职责混合

source 当前同时承担：

- 主要来源
- 原始值说明
- 估算说明
- 复算说明
- 缺失说明
- 冲突说明
- 数据回溯备注

长度统计：

- 平均 62.4 字符
- 最大 92 字符
- >=90 字符 5 条
- 字段上限 VARCHAR(100)

166 条 verified 中 source 标记统计：

- 含“估算”：152
- 含“复算”：85
- 含“未查到”：84
- 含“经验”：148

这些关键词只能用于历史启发式判断，
不能推断整行全部字段具有同一 value_origin。

## canopy_len 元数据债务

数据库 COMMENT 当前仍写“顶梁长度(m)”。

W34D1 已裁定其专业展示语义为：

“支护长度参数”。

不得直接等同于：

- 顶梁长度
- 控顶宽度
- 梁端距

该 COMMENT 属于 schema metadata debt，
W35D1 只记录，不修改数据库。

## param_dependencies

param_dependencies 共 23 条。

其内容包括：

- 历史经验参数
- q_need 参数
- column 标准缸径系列
- 初撑力比
- 27SiMn 材料参数
- 缸筒壁厚公式口径

该表没有 model_id。

结论：

param_dependencies 是全局计算参数 / 公式依赖字典，
不能作为某个支架型号的字段级 provenance。

## support_parts

support_parts 共 83 条。

职责是型号—部件关系：

- model_id
- part_name
- part_type
- material
- quantity

不承担字段级证据职责。

## knowledge_chunks

knowledge_chunks 共 9 条。

职责是 RAG 知识切块：

- source
- loc
- content

chunk 不是稳定的文献来源实体，
因此不直接作为 evidence source master。

## Formula Registry

W34 Formula Registry 继续作为公式编号权威来源。

parameter_evidence.formula_id 只保存类似：

- F-QN-001
- F-COL-002
- F-STR-006
- F-SC-003

W35D1 暂不建立数据库 FK。

## W35D1 结论

新增两层结构：

evidence_sources
    ↓
parameter_evidence
    ↓
support_models

现有表继续保留原职责。

新增结构只补充字段级证据链。
