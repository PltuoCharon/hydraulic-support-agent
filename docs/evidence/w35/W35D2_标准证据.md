# W35D2 标准证据

## 1. 标准编号状态

2026 年煤炭行业标准优化后：

- MT/T 554-1996 → KA/T 554-1996
- MT/T 556-1996 → KA/T 556-1996

新证据文档统一优先使用 KA/T 编号，
历史数据库及旧文档中的 MT/T 编号保留作为历史来源标识。

---

## 2. KA/T 556-1996

标准名称：

《液压支架设计规范》

原编号：

MT/T 556-1996

与 W35D2 相关的已确认内容：

- 支架中心距属于主要设计参数；
- 支护强度应满足矿区煤层地质条件要求；
- 总图及技术文件应标明使用高度范围内支护强度范围；
- 梁端距属于独立设计参数；
- 初撑力一般为额定工作阻力的 60%～85%。

KA/T 556-1996 本身主要规定梁端距等液压支架设计参数；控顶宽度的具体定义由 KA/T 554-1996 附录 D 给出：`B_c = 顶梁长度 + 梁端距`。因此该几何定义已有标准依据。但项目当前 `beam_length` 和 `roof_end_distance` 只是历史默认参数，未经参数级 provenance 核实，历史 F-LEG-002 仍保持 legacy_review。

---

## 3. KA/T 554-1996

标准名称：

《缓倾斜煤层采煤工作面顶板分类》

原编号：

MT/T 554-1996

附录 D2.1 明确：

`B_c = 顶梁长度 + 梁端距`

其中 `B_c` 的标准名称为“控顶宽度”。

附录 D 给出液压支架工作阻力换算关系：

`F_s = P_s × S_c × B_c / K_s`

其中：

- `F_s`：液压支架工作阻力；
- `P_s`：必需的额定支护强度；
- `S_c`：支架中心距；
- `B_c`：支架控顶距；
- `K_s`：液压支架支撑效率。

由此可分解：

`A_control = S_c × B_c`

`F_base = P_s × A_control`

`F_rated = F_base / K_s`

---

## 4. 支撑效率范围

标准给出的典型范围：

- 支掩式掩护支架：0.65～0.75
- 支顶式掩护支架：0.80～0.90
- 支撑掩护式支架：0.80～0.95
- 支撑式支架：0.90～0.96

支撑效率不是全局固定常数。

因此：

`historical eta = 0.9`

不得直接等价为：

`K_s`

---

## 5. W35D2 证据结论

已具备标准证据支持：

1. 控顶面积核心结构：
   `center_dist × control_distance`

2. 基础阻力：
   `q × area`

3. 额定工作阻力修正：
   `/ K_s`

尚不支持：

- `canopy_len == B_c`
- 将项目历史默认 `beam_length`、`roof_end_distance` 直接作为已核实的 `B_c` 输入
- `eta == K_s`
- 全局固定 `safety_factor = 1.2`

需要特别区分：

- 标准几何定义 `B_c = 顶梁长度 + 梁端距` 已有依据；
- 但项目现有 `beam_length=5.2 m`、`roof_end_distance=0.7 m`
  只是历史默认参数，尚不能据此自动生成可靠的 `B_c`。

因此上述四项均不得作为新主链隐式默认关系。
