# W34D3 页面信息架构

## 产品定位

面向液压支架：

- 智能选型
- 参数设计
- 数据查询
- 工程分析
- 知识与证据管理

的智能辅助原型平台。

页面视觉定位：

Industrial Engineering Intelligence
工业工程智能分析软件。

避免：

- 普通后台式菜单堆叠
- 赛博朋克
- 霓虹装饰
- 大面积无意义渐变
- 与工程数据无关的动画

---

## 一级模块

### 1. 工作台

作用：

项目与任务总览。

内容：

- 当前设计任务
- 最近选型任务
- 数据版本
- 数据完整度
- 计算状态
- 最近生成的图纸/模型/仿真
- 风险与待处理项

---

### 2. 智能选型

子模块：

- 工况输入
- 分步选型
- 对话选型
- 推荐结果
- 支架对比

原则：

只保留用户完成一次“工况 → 推荐 → 对比”的业务流程所需入口。

---

### 3. 支架数据库

子模块：

- 支架型号
- 矿区/工作面
- 矿区地图
- 架型谱系
- 制造商
- 数据质量

需要明确：

地图显示“可地图化矿区 / 可用矿区”，
不得把坐标缺失误解成数据数量冲突。

---

### 4. 设计计算

子模块分组：

总体设计
- 支护需求

执行元件
- 立柱
- 千斤顶

液压系统
- 阀组
- 管路
- 泵站

未来：

- 连接销轴
- 四连杆参数

所有计算模块遵循：

计算内核
+ Formula ID
+ 来源
+ API
+ 页面
+ Benchmark
+ Agent Tool

---

### 5. 图纸·模型·仿真

子模块：

- 二维图纸
- 三维模型
- 机构运动
- 液压动态
- 结构分析

成熟度等级：

A：工程参数较完整
B：概念参数模型
C：仅示意模型

不得把 B/C 等级展示为完整工程设计模型。

---

### 6. 知识与证据

子模块：

- 公式库
- 参数来源
- 文献知识
- 数据版本
- 计算记录
- 审计与证据

用于回答：

- 这个参数来自哪里？
- 为什么使用这个公式？
- 该计算基于什么假设？
- 当前数据是否为估算？
- 当前公式处于 active 还是 legacy_review？

---

## 全局 AgentDock

智能体不再作为唯一独立页面。

桌面端右下角固定入口：

AI 智能助手

打开约 400~440px 抽屉。

智能体自动接收当前上下文：

- 当前页面
- 当前工况
- 当前支架
- 当前计算模块
- 当前 Formula ID
- 当前结果

例如：

在立柱页：

“为什么圆整到320mm？”

在谱系页：

“筛选4~6m且18000kN以上支架。”

在证据页：

“F-COL-001来源是什么？”
