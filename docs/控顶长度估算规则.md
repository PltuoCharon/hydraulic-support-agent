# 控顶长度（canopy_len）经验估算规则 v1.0
定义：canopy_len = 有效控顶长度 L（顶梁长度+梁端距，m），用于 q = P/(B·L)。

局限：估算值仅用于批量复算与展示，选型推荐主链路仍以实测 intensity 为准。
