# 控顶长度（canopy_len）经验估算规则 v1.0
定义：canopy_len = 有效控顶长度 L（顶梁长度+梁端距，m），用于 q = P/(B·L)。
标定锚点：ZY12000/28/62D(5.14)、选型通式LD4.5+LK0.5(5.0)、ZY3000/13/22(3.92)、
ZY3000/07/14(3.9~4.5直接值)、ZF15000/28/52(6.08)。来源见工作日志 W25-D2。
规则：架型前缀分组 + height_max 高度段，回填区间中值，source 标注"按架型经验估算"。
局限：估算值仅用于批量复算与展示，选型推荐主链路仍以实测 intensity 为准。
