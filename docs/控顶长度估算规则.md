# 控顶长度（canopy_len）经验估算规则 v1.0
定义：canopy_len = 有效控顶长度 L（顶梁长度+梁端距，m），用于 q = P/(B·L)。
标定锚点（库内实测8条，2026-09-10 查 support_models 验证）：
  ZY系: ZY6800/17/35(h3.5)->4.20, ZY8000/20/40(h4.0)->4.20,
        ZY12000/28/58(h5.8)->4.80, ZY12000/28/62D(h6.2)->4.80
  ZZ系: ZZ5200/13/28(h2.8)->3.60, ZZ9600/22/45(h4.5)->4.50, ZZ10000/25/50(h5.0)->4.50
  ZF系: ZF15000/25/45(h4.5)->5.20 (单锚点, 其余段为外推, 不确定性高)
规则：架型前缀分组 + height_max 高度段，回填区间中值，source 标注"按架型经验估算"。
局限：估算值仅用于批量复算与展示，选型推荐主链路仍以实测 intensity 为准。
