# W22 周报：工况输入页与矿区选择页

## 目标
用户两条路径进入匹配：手动输参数，或选矿区自动带出参数。✅ 达成

## 完成内容
| 天 | 内容 | 产出 |
|---|---|---|
| D1 | vue-router | 三路由 /input /areas /result + 导航壳（hash 模式刷新不丢） |
| D2 | 工况表单 | el-form 11 字段（核心参数+工况档案分区）+ 校验规则；MatchReq 上限对齐 25 |
| D3 | 提交链路 | Pinia store 存条件/结果 → 跳转结果页卡片展示（相似度标/diffs/溯源） |
| D4 | 矿区卡片页 | 网格卡片（类别/厚度/倾角/埋深/瓦斯）+ 选中描边 |
| D5 | 自动回填 | 选中矿区 → prefillFromArea → 表单回填可再修改 |
| D6 | 体验细节 | 空态×3、防重复提交、错误提示统一 |
| D7 | 验收 | 后端四闸门 + 前端五项人工验收 |

## 关键技术决策
- 响应拦截器统一拆包 `{code,data,msg}`，组件只面对 data；
- Pinia store 承载"矿区→表单→结果"的跨页数据流，替代路由带参（字段多易超长）；
- /api/areas 列表项自带全部工况字段，免去单独 conditions 接口；
- 后端当前版本由 厚度+倾角 驱动匹配，表单全字段作为工况档案采集，论文如实说明。
