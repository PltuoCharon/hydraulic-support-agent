## 2. W33 已完成内容

### 2.1 支护需求计算

实现三式并算：

- p1：载荷估算法
- p2：老顶来压步距法
- p3：统计公式法

输出：

- p1_mpa
- p2_mpa
- p3_mpa
- q_need_mpa
- governing

采用三式最大值作为需求支护强度。

谢桥基准：

- hm = 6.0 m
- L1 = 25 m
- Lp = 15 m
- Bc = 5 m
- N = 1.33

结果：

- p1 = 0.90 MPa
- p2 = 0.70 MPa
- p3 = 0.82 MPa
- q_need = 0.90 MPa

注意：

当前计算结果为需求支护强度，不等同于支架工作阻力。
由支护强度进一步转换为工作阻力时，还需要统一有效支护面积、
控顶宽度、支架中心距及支护效率等参数定义。

### 2.2 支护需求参数语义修正

W33D6 对 UI/API/计算内核中文语义进行了统一：

- L1：老顶初次来压步距
- Lp：基本顶周期来压步距
- Bc：控顶宽度
- N：直接顶充填系数（直接顶厚度/采高）

同时修正前端输入范围，使其覆盖后端合法范围。

新增静态守门测试，防止未来前端标签及输入范围再次漂移。

### 2.3 立柱缸径设计

实现：

- 理论缸径反算
- 标准缸径向上圆整
- 标准缸径实际柱力复算
- 初撑力比计算
- 初撑力比区间校核

D3基准：

- 工作阻力 2533 kN
- 立柱数 1
- 工作压力 31.5 MPa
- η = 1.0

结果：

- 理论缸径约 320.0 mm
- 标准缸径 320 mm
- 实际柱力约 2533.4 kN

### 2.4 立柱强度校核

实现：

- 材料许用应力计算
- 薄壁公式
- 中壁公式
- 厚壁公式
- 最大应力安全系数
- 欧拉稳定性校核

当前已核实材料：

27SiMn

程序采用：

σs = 835 MPa

σb 当前未取得足够可靠公开依据，因此保持 NULL，
不进行推测或自动补全。

D4复核示例：

- D = 200 mm
- p = 43.4 MPa
- σallow = 417.5 MPa

结果：

- 理论壁厚 = 10.4 mm
- 薄壁公式档

应力校核：

- σmax = 656.7 MPa
- 安全系数 = 1.27
- 判定通过

欧拉稳定构造例：

- 临界载荷约 5082.8 kN
- 稳定安全系数约 2.54

注意：

欧拉稳定案例中的 E、I、L、载荷为公式验证构造参数，
不能与文献壁厚实例合并表述为同一矿井实测工况。

## 3. API
