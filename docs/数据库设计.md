
# hydraulic_support 数据库设计文档

## 业务问题（系统必须回答）
- Q1：某矿区某工况下在用/可选哪些支架？
- Q2：某型号支架由哪些部件组成，关键参数多少？
- Q3：某设计参数变化时，哪些指标需按什么公式重算？

## 表结构总览
| 表 | 回答的问题 | 核心字段 |
|---|---|---|
| mining_areas | Q1 | 矿区名、煤层厚度 |
| working_conditions | Q1 | 采高、顶板/底板条件、所属矿区 |
| support_models | Q1/Q2 | 型号、架型、阻力、高度范围 |
| support_parts | Q2 | 部件名、规格、数量、所属支架 |
| param_dependencies | Q3 | 公式名、表达式、输入、输出 |

## 版本记录
- v1.0（2026.07.25）：初版五表设计

- v1.1（2026.07.29）：修正缺陷——working_conditions 增加 support_id 外键指向
  support_models。原因：v1.0 中工况与支架无关联，无法回答 Q1"某矿区在用
  什么支架"。教训：建表前应先用业务查询反推关联路径是否完整。
