# 07 前端工程化（Vue3 + Vite + Element Plus）

## 概念
- **Vite**：开发服务器+构建工具，HMR 热更新（改代码页面即时变）；
- **Vue3 组合式 API**：`<script setup>` 里 ref/reactive 声明响应式数据；
- **Element Plus**：桌面端组件库（el-table/el-button/el-form/el-alert）；
- **axios**：HTTP 客户端，拦截器统一处理响应格式和错误。

## 本项目用法（W21）
- 目录：`web/` 与 `app/` 平级，同仓管理；
- 代理：vite.config.js 把 `/api` 转发到 127.0.0.1:8000，
  前端代码零硬编码地址，开发态无跨域问题；
- 封装：`src/api/index.js` 响应拦截器拆包 `{code,data,msg}`，
  组件只面对 data；错误统一 ElMessage 弹出；
- 组件化：App.vue 管数据，AreaList.vue 管展示，
  props 下行 / emit 上行（单向数据流）。

## 踩坑
1. **307 重定向**：FastAPI 路由带尾斜杠时，不带斜杠的请求被 307 跳转，
   axios 虽能跟随，但直接写对路径（/api/areas/）最干净；
2. **端口占用**：旧 dev server 不退出时新 vite 会自动换 5174，
   验收前 `pkill -f vite` / `pkill -f uvicorn` 清场；
3. **venv 会掉**：新开终端没有 (venv) 前缀时 uvicorn 找不到（退出码127），
   先 `source venv/bin/activate`；
4. **node_modules 必须 ignore**：Vite 模板自带 .gitignore，
   提交前确认 node_modules 和 dist 没进 git。
